# Weekly Report

整理目标周报时，只修改 `# 3 总结一下` 和 `# 4 下周计划`，保留其他章节及无法可靠归类的内容。

## 定位周报

按以下顺序确定目标文件：

1. 用户明确给出的 Markdown 文件。
2. 用户给出的 iBrain 根目录，或绝对路径环境变量 `WEEKLY_REPORT_ROOT`。
3. 当前用户目录下存在的 `~/workspace/projects/docs/iBrain`。

周次使用 `YYYY-WW`，对应 `<root>/00.回顾与展望/01.周记/YYYY/YYYY-WW.md`。用户未指定周次时使用当前 ISO 周。路径或文件不明确时询问用户；文件不存在时停止，不自动创建。

## 执行

1. 读取完整周报，确认 `# 1 项目看板` 到 `# 5 学习了些什么` 的章节边界存在。
2. 完整读取 [weekly-format.md](references/weekly-format.md)，按其中规则解析看板、生成总结并合并计划。
3. 替换第 3、4 节，重新读取文件并确认第 1、2、5 节及其后内容未改变。
4. 报告总结条目数、已移除的完成计划数、新增计划数，以及所有需要人工确认的项目。

解析失败、层级含义不明或任务归属不确定时，保留原内容并标记 `⚠️`，不要静默删除或猜测。
