# Git Commit Guide

根据用户指定的提交标识和实际变更生成提交信息。提交标识通常是 Redmine Issue ID，也可以是 `mouse_app` 等其他标识；未指定时先询问，不要猜测。

提交信息严格使用以下结构：

```text
<提交标识>: <中文主题>

1. <具体修改点>
2. <具体修改点>
```

- 主题用中文概括本次提交的主要内容。
- 主题后保留一个空行。
- 修改点使用有序列表，每点一行、简洁具体，正文不超过 20 字。
- 列表项之间不留空行，末行以换行符结束。
- 只描述实际变更，不虚构修改内容或关联 Issue。
- 未经用户明确要求，不执行 `git commit`。
