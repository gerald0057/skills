# 统计语义与对账

## 物理占用

将最终运行/加载地址映射到物理 region，再对 `[start,end)` 求并集。相同 SRAM 的别名用同一 region-id；独立芯片即使坐标相同也用不同 id。映射由已验证的后端/Profile 提供，不凭段名猜硬件。

RAM 执行代码和初始化内容的 Flash 加载副本分别计入对应资源。ROM 不自动计入应用 Flash。Flash 容量取应用链接区域，区分整颗芯片、bank、bootloader、配置区及镜像外壳。

## 类型与模块

代码依据输入段执行属性；只读/初始化/BSS/静态缓冲/静态任务栈属于数据。输出 `.text` 可能混入注册表和常量。向量区可能是地址表或跳转指令，应读取实际属性。

预留与填充分别保留，IRQ 预留段和静态栈名称按项目配置。缺对象/成员/输入段时使用 unknown 并记录 missing_inputs。无法解析的 ELF/归档或矛盾类型属于错误，不能猜测。

模块使用实际 MAP 来源、目录、库成员建立层级，具体规则先于宽泛规则。未匹配来源进入 unattributed；模块未归属不等于类型未知。

同一地址由不同来源合并只计一次，归 linker/shared；填充归 linker/alignment。覆盖范围内缺少输入贡献的字节归 linker/unattributed、类型 unknown。

节点同时有直接内容和后代时，将直接内容移入 self 子项，项目可设置 direct_child_name（例如 driver）。子项已存在则拒绝覆盖。

静态栈按真实符号边界切分、转移归属，避免重复。动态任务/上下文的配置值及堆布局另列；静态剩余布局不能命名为运行时空闲内存。

## 对账不变量

每种类型：互斥叶子之和 = 根节点之和 = 段明细之和 = 总量。父节点等于后代叶子之和。资源的物理区域占用之和等于资源总量。

总量来自物理区间，不来自符号大小求和。别名、共享符号及父子聚合不能重复累计。保留 code/data/reserved/padding/unknown 五类整数 B；MD 展示两种资源细分，PDF 默认 Flash 只显示总量。

类型冲突、容量/地址矛盾或总量不符时拒绝正常统计。真实未知值继续保留，不能为了版面或归零未知而改变数值。
